# GetGantt CLI

Позволяет AI-агенту читать и изменять ваш график GetGantt через команду
gantt.

## Сначала отправьте это агенту

Скопируйте агенту следующий текст. Замените <PROJECT_ID> на ID своего
проекта. Если ID неизвестен, напишите агенту: «Сначала покажи мои проекты».

    Ты управляешь моим графиком GetGantt через CLI gantt.

    Мой проект: <PROJECT_ID>

    Перед началом:
    - проверь, что команда gantt доступна;
    - проверь авторизацию;
    - работай только с указанным проектом;
    - сначала прочитай текущий график и найди нужные задачи;
    - перед любым изменением сначала покажи мне план и выполни preview;
    - не применяй изменение без моего отдельного подтверждения;
    - после изменения сообщи, что изменилось и какая версия графика стала новой.

    Для чтения используй gantt --json.
    Не выдумывай ID задач или проекта. Если что-то неоднозначно — спроси меня.

После этого можно писать агенту обычными словами:

    Покажи все этапы работ.
    Найди задачу «Фундамент» и покажи её зависимости.
    Создай этап «Монтаж» длительностью 10 рабочих дней.
    Поставь задачу «Установка окон» после «Кладки стен».
    Сдвинь весь график на 3 рабочих дня.
    Удали задачу «Черновик».

## Что нужно сделать один раз

### 1. Установить CLI

На компьютере, где агент запускает команды, выполните:

    npm install --global getgantt-cli
    gantt --help

Нужен Node.js 22 или новее.

### 2. Подключить аккаунт GetGantt

Выпустите personal access token в личном кабинете GetGantt, затем выполните:

    gantt auth login

Вставьте токен в скрытое поле. После этого проверьте подключение:

    gantt auth status

Токен не нужно отправлять агенту в чат. Если агент работает на другом
компьютере или в облаке, CLI и авторизацию нужно настроить в его окружении.

## Как указать проект

Самый надёжный вариант — передать агенту ID проекта в стартовом сообщении:

    Мой проект GetGantt: 3dbd4a66-9dd8-4da1-93d2-1bfe6459a14f

Если ID неизвестен, агент может показать доступные проекты. Попросите его:

    Покажи список моих проектов GetGantt и дождись, пока я выберу один.

После выбора агент должен использовать именно этот проект. Не выбирайте проект
по обрывку названия, если есть несколько совпадений.

## Что умеет агент

Агент может:

- показать проект, этапы и задачи;
- найти задачу по названию;
- показать иерархию и зависимости;
- проверить расписание;
- создать новые этапы и задачи;
- изменить название, прогресс, объём и единицу работ;
- переместить задачу в другой этап;
- связать или удалить зависимость;
- сдвинуть расписание;
- удалить задачу после подтверждения.

Для каждого изменения агент сначала делает preview. Preview только показывает
планируемый результат и ничего не меняет. Изменение считается выполненным,
только когда агент сообщил об успешном применении и новой версии графика.

## Если нужно несколько аккаунтов или проектов

Можно сохранить несколько аккаунтов:

    gantt auth login --name work
    gantt auth login --name personal
    gantt auth profiles list
    gantt auth profiles use work

Для конкретной команды проект можно указать явно:

    gantt --project <PROJECT_ID> --json project show

## Если агент не видит CLI

Проверьте в том же окружении, где работает агент:

    gantt --help
    gantt auth status

Если первая команда не работает, CLI не установлен или не добавлен в PATH.
Если не работает вторая, выполните gantt auth login в этом окружении.

## Безопасность

- не передавайте personal access token в сообщениях агенту;
- не вставляйте токен в команду после --token;
- удаление и массовый сдвиг выполняйте только после проверки preview;
- всегда указывайте проект явно, если у аккаунта их несколько;
- при неоднозначном названии задачи просите агента сначала показать варианты.
